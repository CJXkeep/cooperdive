> 来源：基于 DeepSeek 对话产出的开发框架细化而成
> 免责声明：本文档为策略开发框架，不构成任何投资建议。所有阈值、仓位建议均为示例，需独立回测与风险判断。

## 一句话定位

把"前半年持有、后半年抛"这类**日历锚点策略**，改造成**信号驱动、状态机管理**的监控系统。核心不是预测危机，而是识别大秦铁路（601006）从"防御抗跌"进入"补跌阶段"的边际变化，并在底部区域识别回补时机。

## 与 CopperPrice 的关系

本模块已物理合并进 CopperPrice 仓库，与既有铜陵有色看板（`copper/`）**平级独立**：

| 项 | 位置 |
|----|------|
| 代码包 | `daqin/`（与 `copper/` 平级） |
| 设计文档 | `docs/daqin/`（本目录） |
| 数据 | `data/daqin.db`（独立 SQLite，与 `data/copper.db` 互不干扰） |
| 阈值 | `daqin/thresholds.yaml` |
| 手工数据 | `daqin/manual_data/` |
| 回测输出 | `daqin/output/`（gitignore） |

复用关系：网络重试/代理处理复用 `copper/netutil.py`；调度、看板、容器部署在 M1/M6 逐步并入仓库统一设施。

## 核心策略结论（来自前期研究）

1. 大秦铁路在危机中呈三阶段规律：**危机初期相对抗跌 → 深化期补跌（急跌）→ 危机后缓慢修复（跑输成长股）**。
2. 补跌由**需求端边际恶化**触发（如 2008 年秦皇岛库存升至 800 万吨），而非日历。
3. 当前（2026-09）背景：10Y 美债收益率触及 5.045%，大秦股息率约 4.6%，利差已倒挂，"类债券替代"逻辑削弱；但 PB 约 0.58 倍破净 + 负债率 15.88% 提供估值修复期权。
4. 因此监控框架的三条主线：**宏观利率（美债）+ 行业需求（煤炭库存/运量）+ 市场结构（相对强弱/筹码）**。

## 快速开始（规划中）

```bash
# 以下命令均在 CopperPrice 仓库根目录执行
python -m daqin.cli collect      # 拉取/更新数据
python -m daqin.cli compute      # 计算指标
python -m daqin.cli signal       # 输出当日状态
python -m daqin.cli backtest --event 2008
streamlit run daqin/dashboard/app.py   # 可视化面板
```
