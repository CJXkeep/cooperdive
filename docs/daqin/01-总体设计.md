# 01 总体设计

> 版本：v0.1 | 2026-09-20 | 并入 CopperPrice 仓库：2026-09-20 | 免责声明：策略开发框架，不构成投资建议，阈值均为示例，需回测校准。
>
> 路径约定：`daqin/`、`copper/`、`docs/`、`scripts/` 均相对仓库根（CopperPrice/），其余模块路径（如 `signals/`）相对 `daqin/` 包。

## 1. 背景与目标

### 1.1 策略来源

前期研究结论：大秦铁路（601006）在系统性危机中呈"初期抗跌 → 中期补跌 → 后期缓慢修复"三阶段规律，补跌触发点是**需求端边际变化**（秦皇岛库存、大秦线运量），而非时间。原方案"前半年持有、后半年抛"的时间锚点过于脆弱，故本项目改为：

- **监控**：日/周频采集宏观、行业、公司、市场四类数据；
- **识别**：规则引擎 + 状态机判定当前危机阶段（S0-S5）；
- **输出**：状态信号 + 仓位参考 + 告警；
- **验证**：用 2008 / 2015 / 2020 三场危机回测校准阈值。

### 1.2 MVP 目标与验收口径

| 目标 | 验收口径 |
|------|----------|
| 数据层 MVP | 美债10Y、大秦日线、股息率、秦皇岛库存、大秦线月运量五类数据可持续入库 |
| 指标层 | 利差、同比/环比、均线、相对强弱等指标每日自动计算 |
| 信号层 | 状态机输出 S0-S5 当日状态，触发规则留痕 |
| 回测层 | 2008/2015/2020 三个事件窗口跑通，输出状态切换图与净值对比 |
| 告警层 | 状态进入 S2/S3 时推送邮件/钉钉 |

### 1.3 非目标

- 不做自动交易下单，只输出信号与仓位参考；
- 不做高频，最小粒度日频，行业数据周频/旬频；
- 不预测危机何时发生，只识别"当前处于哪个阶段"。

## 2. 系统架构

### 2.1 分层架构

```
┌────────────────────────────────────────────────────────────┐
│ 展示/告警层  daqin/dashboard/app.py (Streamlit) | alerts/     │
├────────────────────────────────────────────────────────────┤
│ 信号层      signals/rules.py + state_machine.py             │
│             指标输入 → 规则判定 → 状态机 → 转换防抖 → 留痕      │
├────────────────────────────────────────────────────────────┤
│ 指标层      indicators/{macro,coal,company,market}.py       │
│             利差 / 同比环比 / 均线 / 相对强弱 / 量比            │
├────────────────────────────────────────────────────────────┤
│ 数据层      collectors/{fred,akshare_stock,coal_manual}     │
│             storage/db.py (data/daqin.db)                   │
├────────────────────────────────────────────────────────────┤
│ 回测层      backtest/{events,engine}.py                     │
│             历史事件窗口回放 → 状态序列 → 净值/回撤对比          │
└────────────────────────────────────────────────────────────┘
```

依赖方向：上层依赖下层；回测层复用指标层与信号层的**纯函数**。

与 copper 模块的关系：两模块平级独立、互不 import 业务代码；网络层（`copper/netutil.py`）作为仓库级公共设施直接复用。

### 2.2 关键设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 仓库 | 并入 CopperPrice，`daqin/` 与 `copper/` 平级 | 复用采集/存储模式、调度器与容器部署，少一套运维 |
| 语言 | Python 3.12（与 CopperPrice 一致） | 数据生态成熟，akshare/FRED 库完善 |
| 存储 | SQLite 单文件 `data/daqin.db` | 与 `copper.db` 独立；宽表 + metrics + signal_log 结构；DDL 预留迁移 PostgreSQL |
| 指标计算 | pandas | 向量化，与回测引擎同构 |
| 回测引擎 | 自研简化事件回放（约 200 行） | 状态机是离散规则，通用框架（vectorbt/backtrader）对自定义状态机支持弱，自研可控 |
| 配置 | YAML `daqin/thresholds.yaml`，阈值全部外置 | 阈值需反复回测校准，调参不改代码 |
| 网络层 | 复用 `copper/netutil.py` | 代理处理/重试逻辑与 copper 一致，避免重复维护 |
| 调度 | 手动 CLI 起步；并入仓库统一 scheduler（21:30 轮次） | 21:30 满足"美债 t-1 可得 + A 股收盘"约束，与 copper 采集同轮跑 |
| 可视化 | Streamlit `daqin/dashboard/app.py` | 与 copper 同栈；M6 决定单服务多页面或双服务 |
| 告警 | SMTP 邮件 + 钉钉 Webhook | 零成本 |

## 3. 核心流程

### 3.1 日常运行

```
[定时(统一调度 21:30) / 手动] python -m daqin.cli collect → 入库(data/daqin.db)
                     ↓
              compute（raw 表 → metrics 表）
                     ↓
              signal（规则 → 状态机 → signal_log + 当日建议）
                     ↓
         ┌── 状态变化且 ∈ {S2,S3} → alerts 推送（变化才推）
         ├── 状态未变化 → 每日收盘后推送状态日报（可配置开关）
         └── 全量数据 → daqin 面板展示
```

### 3.2 回测

```
backtest/events.py 定义事件窗口
   ↓
backtest/engine.py 逐日回放历史 metrics（含手工回填数据）
   ↓
复用 signals/ 规则与状态机（纯函数、无 IO）
   ↓
输出：状态切换图、策略净值 vs 买入持有、最大回撤/夏普、交易明细
```

**关键约束**：信号层必须是纯函数（输入 DataFrame/dict，输出状态），不得直接读库——回测与实盘共用同一套逻辑的前提。

## 4. 状态机概览（详见 03 文档）

| 状态 | 名称 | 一句话定义 | 参考仓位（示例） |
|------|------|-----------|----------------|
| S0 | 正常防御 | 无宏观/需求风险 | 60%（底仓收息） |
| S1 | 危机初期防御 | 美债10Y>5% 或大盘急跌，大秦相对抗跌 | 60%（不追高） |
| S2 | 补跌预警 | 需求指标恶化 + 相对强势松动 | 减 1/3 → 40% |
| S3 | 补跌确认 | 放量破关键均线 / 单日大跌>5% | ≤40% 下限再降 |
| S4 | 底部观察 | 破净 + 高股息 + 运量降幅收窄 | 停止减仓，分批回补 |
| S5 | 修复期 | 运量同比转正 + 库存下降 | 逐步回补至 60% |

## 5. 数据主线（详见 02 文档）

| 主线 | 核心字段 | 频率 | 来源 |
|------|---------|------|------|
| 宏观利率 | us10y, us10y_real, us10y_ie | 日 | FRED（DGS10/DFII10/T10YIE） |
| 行情估值 | daqin_close/pb/dividend_yield, csi300_close | 日 | akshare |
| 行业需求 | qhd_inventory, qhd_coal_price_5500, 电厂日耗 | 周 | 手工 CSV（CCTD/秦皇岛煤炭网） |
| 公司经营 | dq_line_volume, dq_line_volume_yoy | 月/旬 | 巨潮公告爬虫或手工 |
| 筹码结构 | inst_holding_ratio, holder_count | 季 | 财报/东方财富 |

## 6. 风险声明（概要，详见 05 文档）

数据可用性（库存/运量无免费稳定 API）、阈值需回测校准、能源转型致历史规律失效、政策突变（运价/安检）、补跌急跌滑点大。
