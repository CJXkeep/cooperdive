## 1. 数据字典

命名约定：小写下划线；`_yoy` 同比，`_wow` 周环比，`_mom` 月环比，`_20d` 20日窗口。

### 1.1 宏观日频表 `macro_daily`

| 字段 | 类型 | 说明 | 来源 |
|------|------|------|------|
| date | TEXT (YYYY-MM-DD, PK) | 交易日 | - |
| us10y | REAL | 10年期美债收益率 % | FRED: DGS10 |
| us10y_real | REAL | 10年期 TIPS 实际收益率 % | FRED: DFII10 |
| us10y_ie | REAL | 10年盈亏平衡通胀率 % | FRED: T10YIE |
| us10y_20d_chg | REAL | us10y 较 20 个交易日前的变化（bp） | 计算列 |

### 1.2 行情日频表 `stock_daily`

| 字段 | 类型 | 说明 | 来源 |
|------|------|------|------|
| date | TEXT PK | 交易日 | - |
| daqin_close / daqin_high / daqin_low | REAL | 大秦铁路行情（元，复权口径见 §4.3） | akshare |
| daqin_volume | REAL | 成交量（股） | akshare |
| daqin_amount | REAL | 成交额（元） | akshare |
| daqin_pb | REAL | 市净率 | akshare 估值接口或计算 |
| daqin_pe_ttm | REAL | PE-TTM | 同上 |
| daqin_dividend_yield_ttm | REAL | 股息率 TTM % | 计算或接口 |
| csi300_close | REAL | 沪深300收盘 | akshare |

### 1.3 行业周频表 `industry_weekly`

| 字段 | 类型 | 说明 | 来源 |
|------|------|------|------|
| week_end | TEXT PK | 周五日期 | - |
| qhd_inventory | REAL | 秦皇岛港煤炭库存（万吨） | 手工：秦皇岛煤炭网/CCTD |
| qhd_inventory_wow | REAL | 库存周环比 % | 计算列 |
| qhd_inventory_yoy | REAL | 库存同比 % | 计算列 |
| qhd_coal_price_5500 | REAL | 秦皇岛 5500 大卡动力煤价（元/吨） | 手工：CCTD |
| pit_port_spread | REAL | 坑口-港口价差（元/吨） | 手工 |
| pp_daily_consume | REAL | 沿海八省电厂日耗（万吨） | 手工：CCTD |
| pp_available_days | REAL | 电厂库存可用天数（天） | 手工 |

### 1.4 公司月频表 `company_monthly`

| 字段 | 类型 | 说明 | 来源 |
|------|------|------|------|
| month | TEXT (YYYY-MM, PK) | 月份 | - |
| dq_line_volume | REAL | 大秦线货物运输量（万吨） | 巨潮月度公告 |
| dq_line_volume_yoy | REAL | 大秦线运量同比 % | 计算列 |
| dq_coal_volume | REAL | 公司煤炭发送量（万吨） | 公告 |
| dq_coal_volume_yoy | REAL | 同比 % | 计算列 |
| dq_10d_volume_yoy | REAL | （可选）旬度运量同比 %，更灵敏 | 公告 |

### 1.5 筹码季频表 `holder_quarterly`

| 字段 | 类型 | 说明 |
|------|------|------|
| quarter | TEXT (YYYYQn, PK) | 季度 |
| inst_holding_ratio | REAL | 机构持股比例 % |
| holder_count | INTEGER | 股东户数 |
| holder_count_chg | REAL | 股东户数环比变化 % |

### 1.6 指标日频表 `metrics_daily`（指标层输出，信号层输入）

| 字段 | 说明 |
|------|------|
| date, us10y, us10y_20d_chg | 宏观 |
| spread_daqin_us10y | 大秦股息率(TTM) - us10y（百分点） |
| rel_strength_20d | 大秦 20 日累计收益 - 沪深300 20 日累计收益（百分点） |
| ma20/ma60/ma120 | 大秦均线 |
| volume_ratio_5d | 当日成交额 / 5日均成交额 |
| drawdown_20d_csi300 | 沪深300 自 20 日高点的回撤 % |
| rs_60d_peak | 近 60 日 rel_strength_20d 最大值（K1 判定用） |
| qhd_inv_level / qhd_inv_wow / qhd_inv_wow_streak | 秦皇岛库存绝对值/周环比/连续上行周数（周表按发布日对齐后 ffill 到日频） |
| dq_vol_yoy / dq_vol_yoy_lag1 / dq_vol_yoy_lag2 | 大秦线运量同比及其前两期值（月表 ffill，供 S4"降幅连续收窄"判定） |

> 约束：信号层是只读 `metrics_daily` 单行的纯函数，因此**所有跨周期判定所需字段必须在指标层预计算为日频列**（如 streak、lag1/lag2），禁止信号层回查周表/月表。

## 2. 数据源清单与可用性

| 数据 | 首选来源 | 接口/方式 | 可用性 | 备选 |
|------|---------|-----------|--------|------|
| 美债 10Y/实际利率/通胀预期 | FRED | `fredapi`（DGS10/DFII10/T10YIE） | 免费，历史完整 | 手工 CSV |
| 大秦/沪深300 日线 | akshare | `stock_zh_a_hist`, `index_zh_a_hist` | 免费 | tushare |
| PB/PE/股息率 | akshare | `stock_a_indicator_lg`（乐咕）或计算 | 免费，需验证口径 | 东财爬虫 |
| 秦皇岛库存 | 秦皇岛煤炭网/CCTD | 手工 CSV（MVP），后期爬虫 | 部分付费 | Wind 终端截图录入 |
| 煤价/坑口价差/电厂日耗 | CCTD | 手工 CSV | 部分付费 | 行业公众号周报 |
| 大秦线月度运量 | 巨潮资讯公告 | 手工（MVP）→ 公告爬虫 | 免费但需爬 | 公司官网月报 |
| 机构持股/股东户数 | 东方财富/财报 | 手工（季频，工作量小） | 免费 | tushare |

**MVP 原则**：凡无免费稳定 API 的（库存、煤价、运量），一律先手工 CSV 周更/月更，格式见 §3.3；自动化放在 M6。

## 3. 采集方案

### 3.1 FRED 采集（collectors/fred.py）

```python
from fredapi import Fred
def fetch_macro(fred: Fred) -> pd.DataFrame:
    out = pd.DataFrame(index=pd.date_range("2007-01-01", pd.Timestamp.today()))
    out["us10y"] = fred.get_series("DGS10")
    out["us10y_real"] = fred.get_series("DFII10")
    out["us10y_ie"] = fred.get_series("T10YIE")
    return out.dropna(how="all")
```

FRED key 从环境变量 `FRED_API_KEY` 读取（见 `daqin/thresholds.yaml` 的 `data.fred_api_key_env`），不入库不入 git。

### 3.2 akshare 采集（collectors/akshare_stock.py）

```python
import akshare as ak
def fetch_daqin() -> pd.DataFrame:
    df = ak.stock_zh_a_hist(symbol="601006", period="daily",
                            adjust="qfq", start_date="20070101")
    df = df.rename(columns={"日期": "date", "收盘": "daqin_close",
                            "最高": "daqin_high", "最低": "daqin_low",
                            "成交量": "daqin_volume", "成交额": "daqin_amount"})
    return df
```

调用统一经 `copper/netutil.call_with_retry` 包装重试（复用仓库既有网络层）。

### 3.3 手工 CSV 模板（daqin/manual_data/）

```
industry_weekly.csv  → week_end,qhd_inventory,qhd_coal_price_5500,pit_port_spread,pp_daily_consume,pp_available_days
company_monthly.csv  → month,dq_line_volume,dq_coal_volume
holder_quarterly.csv → quarter,inst_holding_ratio,holder_count
```

录入规范：值缺失留空不填 0；单位固定（万吨、元/吨、%）；每周日录入上周数据。

## 4. 存储设计

### 4.1 DDL（SQLite，库文件 data/daqin.db）

```sql
CREATE TABLE IF NOT EXISTS macro_daily (
  date TEXT PRIMARY KEY, us10y REAL, us10y_real REAL, us10y_ie REAL);
CREATE TABLE IF NOT EXISTS stock_daily (
  date TEXT PRIMARY KEY,
  daqin_close REAL, daqin_high REAL, daqin_low REAL,
  daqin_volume REAL, daqin_amount REAL,
  daqin_pb REAL, daqin_pe_ttm REAL, daqin_dividend_yield_ttm REAL,
  csi300_close REAL);
CREATE TABLE IF NOT EXISTS industry_weekly (
  week_end TEXT PRIMARY KEY,
  qhd_inventory REAL, qhd_coal_price_5500 REAL,
  pit_port_spread REAL, pp_daily_consume REAL, pp_available_days REAL);
CREATE TABLE IF NOT EXISTS company_monthly (
  month TEXT PRIMARY KEY, dq_line_volume REAL, dq_coal_volume REAL);
CREATE TABLE IF NOT EXISTS holder_quarterly (
  quarter TEXT PRIMARY KEY, inst_holding_ratio REAL, holder_count INTEGER);
CREATE TABLE IF NOT EXISTS metrics_daily (
  date TEXT PRIMARY KEY, us10y REAL, us10y_20d_chg REAL,
  spread_daqin_us10y REAL, rel_strength_20d REAL,
  ma20 REAL, ma60 REAL, ma120 REAL, volume_ratio_5d REAL,
  drawdown_20d_csi300 REAL, rs_60d_peak REAL,
  qhd_inv_level REAL, qhd_inv_wow REAL, qhd_inv_wow_streak INTEGER,
  dq_vol_yoy REAL, dq_vol_yoy_lag1 REAL, dq_vol_yoy_lag2 REAL);
CREATE TABLE IF NOT EXISTS signal_log (
  date TEXT PRIMARY KEY, state TEXT, prev_state TEXT,
  triggered_rules TEXT, position_advice REAL, note TEXT);
```

### 4.2 写入约定

- 全部 upsert（`INSERT ... ON CONFLICT(date) DO UPDATE`），重复运行幂等；
- 采集器只写 raw 表，指标层只写 metrics 表，信号层只写 signal_log；
- 手工 CSV 导入后打印行数与缺失值统计，人工确认。

### 4.3 数据口径注意

- 复权：日线用前复权（qfq），但历史分红基数用于股息率计算时用原始价；
- 股息率 TTM = 近 12 个月每股分红 ÷ 现价；回购按"回购金额 ÷ 现价"折算加回，仅用于 2026E 口径（见 03 §1）；
- **可得性对齐（防未来函数）**：FRED 美债为美东晚间发布，A 股 15:00 收盘时不可得，宏观列统一按 t-1 对齐；周频/月频数据按其发布日对齐到首个可得交易日再 ffill；回测与实盘必须调用同一个对齐函数；
- 实盘执行时点：并入仓库统一调度后随 scheduler 每日 21:30 运行（满足"美债 t-1、当日行情均已可得"约束）；手动运行 `python -m daqin.cli signal` 应在 18:00 后；
- akshare 接口名可能随版本变化，采集器内做接口探活。

## 5. 配置管理（daqin/thresholds.yaml）

所有阈值外置，见 03 文档 §5 完整清单；数据层相关项：

```yaml
data:
  fred_api_key_env: FRED_API_KEY     # 从环境变量读取，不入库不入 git
  hist_start: "2007-01-01"
  manual_data_dir: daqin/manual_data
```

库文件路径 `data/daqin.db` 由 `daqin/config.py` 定义（与 `copper/config.py` 的路径约定一致，支持 `DAQIN_DATA_DIR` 环境变量覆盖，容器内挂载 `/app/data`）。
