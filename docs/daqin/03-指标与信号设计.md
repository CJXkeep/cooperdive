## 1. 指标计算公式

| 指标 | 公式 | 备注 |
|------|------|------|
| us10y_20d_chg | us10y(t) - us10y(t-20交易日)，单位 bp | 宏观升温速度 |
| spread_daqin_us10y | daqin_dividend_yield_ttm - us10y | >1.5 有比价优势；<0 倒挂 |
| rel_strength_20d | 大秦 20 日累计收益% - 沪深300 20 日累计收益% | "相对强势"核心指标 |
| ma20/60/120 | 收盘价移动均线 | MA60 为 S3 关键均线 |
| volume_ratio_5d | 当日成交额 / MA(成交额,5) | >1.5 视为放量 |
| drawdown_20d_csi300 | csi300 / MA(csi300,20日高点) - 1 | <-10% 视为系统性下跌 |
| qhd_inv_wow / yoy | 库存周环比% / 同比% | 需求恶化主指标 |
| dq_vol_yoy | 大秦线运量同比% | 月度；旬度可选 |
| yield_2026e | 2026E 股息率（分红+回购÷净利 × 预测净利 ÷ 市值） | 参考值约 5.1% |

## 2. 信号规则表

规则分为三组，`rules.py` 中每条规则为独立函数：输入 metrics 行，输出 `(bool, reason)`。

### 2.1 宏观组（M 系列）

| 编号 | 规则 | 条件（示例） |
|------|------|-------------|
| M1 | 美债高位 | us10y > 5.0（解除阈值 4.8，滞回） |
| M2（辅） | 美债快速上行 | us10y_20d_chg > +30bp |
| M3（辅） | 利差倒挂 | spread_daqin_us10y < 0 |
| M4 | 系统性下跌 | drawdown_20d_csi300 < -10% |

> 标注（辅）的规则仅用于日报展示与人工参考，不参与状态转换。

### 2.2 需求组（D 系列）—— 补跌预警的核心

| 编号 | 规则 | 条件（示例） |
|------|------|-------------|
| D1 | 库存绝对高位 | qhd_inventory > 780（warn）/ >800（danger，2008 年触发值） |
| D2 | 库存连续累积 | 连续 2 周 qhd_inventory_wow > +5% |
| D3 | 库存同比高增 | qhd_inventory_yoy > +20% |
| D4 | 运量转负 | dq_vol_yoy < 0（月度）或旬度 < -5% |
| D5（辅） | 电厂需求弱 | pp_available_days > 25（库存天数过高） |
| D6（辅） | 煤价跌破长协 | qhd_coal_price_5500 < 长协基准价 |

> D3 参与 demand_bad 判定（= D1∨D2∨D3∨D4）。

### 2.3 市场组（K 系列）

| 编号 | 规则 | 条件（示例） |
|------|------|-------------|
| K1 | 相对强势松动 | rel_strength_20d 由正转负（此前 60 日内曾 > +5） |
| K2 | 放量下跌 | 单日跌幅 > 5% 且 volume_ratio_5d > 1.5 |
| K3 | 破位 | 收盘跌破 MA60 且连续 3 日 < MA60 |
| K4（辅） | 筹码恶化 | inst_holding_ratio 持续下降（季频） |
| K5 | 底部特征 | PB < 0.60 且 股息率 > 5.5% |

## 3. 状态机定义

### 3.1 状态与动作

| 状态 | 名称 | 进入条件摘要 | 动作/仓位（示例） |
|------|------|-------------|------------------|
| S0 | 正常防御 | 非 S1 条件 | 持有底仓 60%，收息 |
| S1 | 危机初期防御 | M1 或 M4 成立，且无 D 系列恶化 | 持有，不追高 |
| S2 | 补跌预警 | (D1∨D2∨D3∨D4) ∧ K1，宏观通常仍处 M1 | 减仓 1/3 → 约 40% |
| S3 | 补跌确认 | K2 或 K3（允许自 S0/S1 跳级进入） | 一次性减至下限 20%（s3_floor） |
| S4 | 底部观察 | K5 ∧ 大秦线运量同比降幅连续 2 个月收窄 | 停止减仓，制定回补计划 |
| S5 | 修复期 | dq_vol_yoy 转正 ∧ 库存连续 4 周下降 | 按步长 10% 分批回补至 60% |

### 3.2 状态转换矩阵

```
      → S0      → S1      → S2      → S3      → S4      → S5
S0      -     M1∨M4   (D1∨D2∨D3∨D4)∧K1   K2∨K3      -          -
S1    M1失效∨超时   -   (D1∨D2∨D3∨D4)∧K1   K2∨K3      -          -
S2    -      D系修复     -          K2∨K3      -          -
S3    -        -      K1复现∧D未修复  -      K5∧降幅收窄     -
S4    -        -        -          -          -      运量转正∧库存降
S5    回补满      -        -          -          -          -
```

要点：

- 允许**向上跳级**（快速危机中 K2/K3 成立时 S0/S1 可直达 S3，不等周频数据），向下始终逐级；S2→S1 允许"解除预警"（需求指标修复）；S3→S2 允许假破位回撤，避免一次震荡降两档；
- **滞回（hysteresis）**：升级阈值与降级阈值不对称（库存升级 780 / 降级 720 万吨；us10y 升级 5.0 / 解除 4.8），防止状态反复横跳；
- 同日多条件冲突时，取"更高风险"状态（S3 > S2 > S1 > S0；S4/S5 由自身条件独立判定）。

### 3.3 防抖规则

| 信号频率 | 确认要求 |
|---------|---------|
| 日频规则（M/K） | 连续 2 个交易日成立才触发转换 |
| 周频规则（D1-D3/D5） | 当周值成立即计入，但 S2 转换需"周频 D + 日频 K"双确认 |
| 月频规则（D4、S4/S5 条件） | 当月值成立即计入，月度数据发布滞后需在 metrics 表标注数据截止日 |

### 3.4 纯函数接口（回测与实盘共用）

```python
# daqin/signals/state_machine.py
def next_state(current: str, row: pd.Series, cfg: Thresholds) -> str:
    """输入当前状态与当日 metrics 行，输出目标状态（未过防抖）。"""

class Debouncer:
    """对日频条件计数，连续 N 日成立才放行。"""
    def feed(self, date, condition: bool) -> bool: ...

def run_daily(metrics: pd.DataFrame, cfg: Thresholds) -> pd.DataFrame:
    """整段回放：逐行 next_state + Debouncer，输出 state 序列与 signal_log。
    实盘每日调用一次；回测整段调用。"""
```

## 4. 信号日志与建议输出

每次状态变化写一行 `signal_log`（`data/daqin.db`）：

```json
{
  "date": "2026-11-06",
  "prev_state": "S1",
  "state": "S2",
  "triggered_rules": ["D2", "K1"],
  "position_advice": 0.40,
  "note": "库存连续2周环比>+5%，相对强势转负"
}
```

当日建议规则：

- 状态不变 → 输出 `HOLD (state)`；
- 升级 → 输出具体调仓幅度与依据规则；
- `note` 字段必须可读，供钉钉/邮件直接推送。

## 6. 伪代码（rules.py + state_machine.py）

```python
def r_m1(row, cfg): return row.us10y > cfg.macro.us10y_high
def r_d2(row, cfg): return row.qhd_inv_wow_streak >= cfg.demand.qhd_inv_wow_weeks \
                       and row.qhd_inv_wow > cfg.demand.qhd_inv_wow_pct
def r_k1(row, cfg): return row.rel_strength_20d < cfg.market.rs_20d_turn_negative \
                       and row.rs_60d_peak > cfg.market.rs_60d_lookback_peak
...

ORDER = {"S0": 0, "S1": 1, "S2": 2, "S3": 3}

def next_state(cur, row, cfg, deb):
    if cur in ("S4", "S5"):
        if cur == "S4" and r_vol_turn_positive(row) and r_inv_down4w(row):
            return "S5"
        return cur                      # S5 回补满后回 S0；退出细节见滞回实现
    # 1) 向上判定（允许跳级）：K 系（快变量）优先于 D 系，D 系优先于 M 系
    target = None
    if deb["k2"].feed(r_k2(row)) or deb["k3"].feed(r_k3(row)):
        target = "S3"
    elif (r_d1(row) or r_d2(row) or r_d3(row) or r_d4(row)) \
            and deb["k1"].feed(r_k1(row)):
        target = "S2"
    elif deb["m1"].feed(r_m1(row)) or deb["m4"].feed(r_m4(row)):
        target = "S1"
    if target and ORDER[target] > ORDER[cur]:
        return target
    # 2) 向下逐级（阈值带滞回：us10y<4.8 才解除 M1；库存<720 才解除 D1；
    #    S1 停留超 60 个交易日且无 D/K 恶化则回 S0）
    return demote(cur, row, cfg, deb)
```

## 7. 边界与已知风险

- 月度运量数据滞后约 5-10 天，S4/S5 判定天然滞后；V 型反转（2020 型）中回补预计滞后 2-3 个月，缓解手段：允许旬度运量（dq_10d_volume_yoy）替代月度；
- 长期高利率常态：us10y 长期 > 5% 时 S1 将常态化（仓位与 S0 相同，仅语义差异），S1 停留超 60 个交易日且无 D/K 恶化则降回 S0；
- 结构性下滑复核线：大秦线运量连续 6 个月同比为负 → 暂停 S4/S5 回补信号并人工复核（区分周期性与结构性下滑）；
- 2008 年秦皇岛库存历史序列难以获取时，D 系列在 2008 回测中降级不可用，仅验证 M+K 链路（详见 04 §3）；
- K5 中"股息率"用 TTM 口径；若公司分红政策突变，需人工复核后再信信号。
