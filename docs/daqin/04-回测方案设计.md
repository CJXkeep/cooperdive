## 1. 回测目标

1. 验证状态机能否在 2008 / 2015 / 2020 三场危机中**正确输出阶段序列**（初期抗跌→预警→确认→底部→修复）；
2. 校准 thresholds.yaml 中全部阈值，使策略相对买入持有的**最大回撤显著下降**，且总收益不显著恶化；
3. 输出可视化的状态切换图，用于人工复盘。

## 2. 历史事件样本（backtest/events.py）

| 事件 | 回放窗口 | 关键锚点 | 备注 |
|------|---------|---------|------|
| 2008 全球金融危机 | 2007-10-01 ~ 2009-06-30 | 2008-01-08 高点 28.45 元；2008-10-31 靓丽三季报当日跌停（触发：秦皇岛库存达 800 万吨）；2008 年底 7.53 元低点；2009 修复 | 核心样本 |
| 2015 A股股灾 | 2015-04-01 ~ 2016-03-31 | 2015-04 高点约 12.48 元；2015-06-18 大盘大跌当日大秦为 2000 亿市值股中唯一收涨；2015-07-02 单日 -9.96% 补跌 | 流动性危机型 |
| 2020 新冠冲击 | 2020-01-10 ~ 2020-12-31 | 2020-02-03 单日 -6.23% 至 7.22 元；H1 净利 -30.65%；全年未创新低，7-8 元区间修复 | 外部冲击型 |
| （可选）2023-10 美债破 5 | 2023-09-01 ~ 2024-03-31 | 10Y 美债盘中破 5% 后一日回落 | 纯宏观压力测试，无危机兑现 |

窗口统一取"危机前 3 个月 ~ 危机后 6-9 个月"，具体日期在 `events.py` 中以常量定义，可调。

**降级规则**：某数据缺失时，对应规则置为 `False` 并在回测报告标注"该事件未覆盖 D 系列"；绝不允许用插值伪造周频行业数据。

## 4. 回测引擎（backtest/engine.py）

### 4.1 设计

自研事件回放（不用 vectorbt），核心约 200 行：

```python
def run_event(event: Event, metrics: pd.DataFrame, cfg: Thresholds) -> BacktestResult:
    states = run_daily(metrics.loc[event.start:event.end], cfg)   # 复用信号层
    nav  = simulate_nav(states, metrics, cfg.position)            # 仓位 → 净值
    bh   = buy_and_hold(metrics.loc[event.start:event.end])
    return BacktestResult(states=states, nav=nav, bh=bh, trades=extract_trades(states))
```

### 4.2 收益模拟规则

- 回放窗口前预留 ≥120 个交易日 warm-up（MA120、us10y_20d_chg 等指标计算需要），窗口首日状态自 S0 起步；
- T 日收盘输出状态 → T+1 日开盘价执行调仓（避免未来函数）；宏观/周频字段统一使用 02 §4.3 的 t-1 可得性对齐；
- 仓位只有档位切换（0.6/0.4/0.2 分批），现金部分默认不计收益；提供 cash_yield 参数（如按货基/短债近似 1.5%）做敏感性对照；
- 忽略交易成本与滑点（MVP），报告中同时给出"含 0.1% 单边成本"敏感性版本；
- 分红再投资（前复权价已隐含）。

### 4.3 评估指标

| 指标 | 定义 | 期望 |
|------|------|------|
| 策略/持有总收益 | 窗口末净值 - 1 | 策略 ≈ 或 > 持有 |
| 最大回撤 | max(峰值-谷值)/峰值 | **策略显著小于持有**（核心指标） |
| 夏普 | 年化超额/波动 | 策略 > 持有 |
| 换手次数 | 档位切换次数 | 少于 6 次/事件（防过拟合） |
| 状态序列 | 各状态出现时点 vs events.py 预定义"补跌起点"锚点 | S2/S3 不晚于锚点后 20 个交易日 |
| 假信号率 | 升级（S1→S2/S2→S3）后 10 个交易日内，大秦相对沪深300 超额收益 < -3% 的比例 | < 50%（辅助） |

## 5. 输出物（daqin/output/）

| 文件 | 内容 |
|------|------|
| `{event}_states.png` | 价格曲线 + 状态色带（S0-S5 底色）+ 关键锚点标注 |
| `{event}_nav.png` | 策略净值 vs 买入持有 |
| `{event}_report.md` | 评估指标表 + 状态切换日志 + 交易明细 |
| `grid_search.csv` | 阈值敏感性扫描结果（见 §6） |

## 6. 阈值校准方法

1. **基准参数**：以 03 文档示例阈值跑三个事件，形成 baseline；
2. **单参数敏感性**：每次只动一个阈值（如 qhd_inv_warn ∈ {740, 760, 780, 800}），观察回撤与假信号率的变化曲面；
3. **网格搜索（克制）**：仅对 4 个核心阈值（qhd_inv_warn、dq_vol_yoy_danger、us10y_high、volume_ratio_confirm）做 ≤ 5×5 网格，共 3 事件；严禁大网格过拟合 3 个样本；
4. **稳健性原则**：参数在邻域内表现平稳才可采纳；对单事件"恰好最优"的参数一律不取；
5. 校准结果写回 `daqin/thresholds.yaml`，并在其 `change_log` 段与 yaml 注释中记录校准日期与依据。

## 7. 回测有效性声明

- 仅 3 个事件样本，统计意义有限，结论只用于"逻辑是否成立 + 量级参考"；
- 2008 年数据降级导致 D 链路仅 2020 一个样本验证，需在报告中明示；
- 未来危机的结构可能不同（能源转型、政策突变），状态机输出应始终与人工研判结合；
- 2020 型 V 型反转中 S4/S5 回补信号预计滞后 2-3 个月（依赖月度运量确认），报告中需单独量化该滞后并与"人工提前回补"基准对照。
