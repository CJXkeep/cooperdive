
## 3. 测试策略

- 指标：用构造序列（已知答案）断言，如 20 日变化、均线、量比；
- 状态机：参数化用例覆盖——全部转换矩阵单元格（含向上跳级）、防抖未确认不转换、滞回降级、多条件冲突取高风险；
- 回测引擎：用 10 行合成行情验证 T+1 执行、档位切换、回撤计算；
- 采集器：mock HTTP，不做真实网络的单测。

## 4. 风险与局限性清单

| 风险 | 影响 | 缓解 |
|------|------|------|
| 秦皇岛库存/运量无免费稳定 API | 数据断更，D 链路失效 | 手工 CSV 周更兜底；录入日历提醒 |
| 阈值过拟合 3 个事件样本 | 实盘失效 | §04.6 校准纪律：单参数敏感性优先、邻域平稳才采纳 |
| 能源转型致运量结构性下滑 | 历史三阶段规律失效 | 每季度复核运量同比中枢；结构性下滑时人工停用框架 |
| 政策突变（运价/安检/进口煤） | 基本面跳变 | signal_log 之外维护人工事件簿 |
| 补跌呈急跌特征 | 信号确认时滑点大 | S2 先减 1/3 的分档设计即为此；回测加成本敏感性 |
| akshare/FRED 接口变动 | 采集失败 | 采集器探活 + 失败告警 + 手工兜底 |
| 股息率口径混乱 | M3/S4 判定失真 | 02 §4.3 固定口径；分红公告后人工复核 |
| 与 copper 模块共用调度/容器引入互相干扰 | 一方失败影响另一方 | 沿用 copper 的失败隔离模式：单数据集失败不拖垮整轮 |
