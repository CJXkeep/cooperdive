## 5. 实现记录

> 只写**已实现的事实 + 为什么**（现在时；不写"计划/预计"）。
> 非直觉的选择按三段记：选择 / Alternatives（为何不选）/ 代价。
> 重要决定升格为 06 的 D-xx 并回链编号；未做完的移入 §6。

- 2026-09-21 **M1 探活与决议处置**：三源实测（见 §1.1）。**六大电停更**是本轮最重要的发现——
  它同时击穿 D5 与 D-22 的 S5 自动核，触发 **D-26**：S5 自动核改为「运量连续 2 月转正」（复用既有列 `dq_vol_yoy`/`lag1`，零 DDL 变更）。
  Alternatives：① 电厂数据改手工 CSV——不选，周频人工成本高且 S5 是退出型信号，延迟无妨但依赖人工不可靠；
  ② 引入 CCTD 等付费/半付费源——不选，与 D-06 的"投入产出比"原则冲突。
  代价：D 系自动核在 2020+ 实际退化为仅 D4（月频），S2/S5 的时间分辨率下降——已同步 M4 预期（D-23/D-26）。

- 2026-09-21 **M1-0 完成**：FRED 三序列入库 5184 行（2006-01-01 起）。本机访问 FRED 需两步：
  **① 显式代理解脱阀**——`netutil` 屏蔽系统代理的补丁会清空一切自动代理检测，新增环境变量 `REPO_HTTP_PROXY`
  （`http_get`/`fetch_text` 支持，不设时行为完全不变）；
  **② FRED 专用请求路径**——同一时点的实验矩阵：裸请求 + 显式代理稳定 200（3 次），
  而共享会话的各种组合（浏览器 UA / 中性 UA / 双键 proxies / Retry 适配器 / 代理 patch）全部超时或 ProxyError，
  根因未完全定位（判定为本机代理与会话配置的环境特异性交互；服务器直连环境下两者等价）。
  选择：`fred._fetch_csv_text`（最小会话 + 显式代理 + 重试）。Alternatives：继续深挖共享会话——不选，投入产出比低。
  验证：**t-1 对齐在真实数据上严格成立**——metrics 的 03-20/23/24/25 分别取到 macro 的 03-19/20/23/24（逐日对应）。
- 2026-09-21 **M1-1 完成**：`collectors/futures.py` + 指标层接入（`zc_close`/`zc_valid`/`zc_dev_20d`）。
  选择：**新浪主连 `futures_main_sina(ZC0)`**。Alternatives：06 §1.1 原定的 `futures_hist_em`——实测该函数映射表无动力煤主连
  （仅具体合约如"焦煤2506"）；`futures_main_sina` 是 copper 长期在用的主连接口。
  代价：`zc_amount` 只能用 `成交量 × 收盘价` 近似（接口不提供成交额）；`zc_valid` 为比值判定，与单位无关。
  实测：首次采集 1760 行；2020 全年有效 243/243，最低 20 日偏离 -6.9%（未触发 D6 阈值，与当年煤价平稳一致）。
- 2026-09-21 **M1-5（采集部分）完成**：`collectors/dividend.py`（巨潮 22 行全历史，`dps = 派息比例 ÷ 10`）。
  **未闭环**：股息率 TTM 需要「不复权价 + 每股净资产」，当前 `stock_daily` 只有 qfq 价——用 qfq 价算历史股息率会系统性高估
  （前复权下调历史价）。处置：下轮新增 `daqin_close_raw` 列与 bps 采集（拟 D-27）。

- 2026-09-22 **M1-2 完成**：`collectors/energy.py`（六大电全历史 1207 行，2016-01-01 ~ 2019-06-21）。
  指标层配套加**停更保护**（`STALE_DAYS = 30`）：距最后观测超过 30 天的交易日置 NULL——否则停更数据被永久前向填充，
  使 D5 在 2020 年误触发（实测确实发生，修正后消失）。
- 2026-09-22 **M1-3 完成**：`collectors/company_report.py`，**148 个月**运量入库（2014-01 ~ 2026-08）。
  选择：**巨潮官方 PDF 链路**（列表定位 → `static.cninfo.com.cn/finalpage/{日}/{id}.PDF` → `pdfplumber`）。
  Alternatives：① 06 §1.1 原定的东财公告详情 API——批量抓取返回 HTML 拦截页（限流），否决（R-11）；
  ② 东财列表 API 的标题——不含数字 ✗。
  代价：PDF 文本需适配公告**措辞变体**，实测四种——语序变更（「完成货物运输量 X」→「货物运输量完成 X」，2022 年中起）、
  「同比持平」（无数字）、当月同比省略（2023 下半年起只给累计同比）、跨句表述（2022-11「全月完成…」）。
  配套：当月同比缺失时用**去年同月运量自算**；区间过滤只限上界（公告跨年发布时仍入库上年 12 月数据）；
  增量起点（默认回看 3 个月）；失败留痕（单篇告警、全失败抛错触发 freshness 红灯）。
- 2026-09-22 **M1-5 闭环**：`collectors/valuation.py`（不复权价 + 季报 bps，4954 行）→ 指标层产出
  `daqin_pb`、`dividend_yield_ttm`、`spread_daqin_us10y`（**D-27**）；同期扩展运量同比（含 `lag1/lag2`、收窄连续月数）
  与电厂可用天数（含高位/正常连续天数）。
  基建配套：`daqin/storage/db.py` 增加**幂等增量迁移**（`_MIGRATIONS`）——`CREATE TABLE IF NOT EXISTS`
  不会给已有表补列，实跑旧库时报 `no column named daqin_close_raw`；现连接时自动 `ALTER TABLE` 补列（附单测）。
- 2026-09-22 **D-28 修复（状态振荡）**：真实数据回放暴露 S2↔S3 高频振荡（2020-04/05 交替换 20+ 次，共 28 次变化）——
  根因是 03 §3.2 的 S3→S2 降级条件与升级条件（K2∨K3）不互斥。加「技术恶化已解除」前提后降至 **9 次**，
  序列回到合理流转（M4+D4 → S1；K3 → S3；K1 且 K3 解除 → S2）。
